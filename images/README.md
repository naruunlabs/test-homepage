# 사진 넣는 곳

아래 이름 그대로 넣으면 자동으로 연결됩니다. 없으면 그 자리는 비워집니다.

| 파일명 | 용도 | 권장 크기 |
|---|---|---|
| `hero.jpg` | 첫 화면 배경 | 1920 × 1080 |
| `master.jpg` | 관장 사진 | 세로 3:4 |
| `program1.jpg` ~ `program6.jpg` | 교육과정 | 가로 4:3 |
| `facility1.jpg` ~ `facility6.jpg` | 시설 | 가로 4:3 |
| `og.jpg` | 카카오톡 공유 이미지 | 1200 × 630, 300KB 이하 |

`blog/` 폴더는 네이버 블로그 사진이 자동으로 저장되는 곳입니다. 직접 넣지 마세요.
